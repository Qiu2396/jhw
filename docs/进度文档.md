## 2026-09-08 · v0.3.0 跨页不断播的音乐播放器 + 日间/夜间双主题

**背景**：用户反馈「切到小说页音乐就停了」，要求支持边听歌边看小说、推荐歌单、顺序播放；黑色主题改为夜间模式并新增日间主题；随后追加治愈系歌单与文案、界面细节对齐优化。

### 断播根因

MusicView（含 APlayer 实例）挂在 `v-else-if` 条件分支里，切到小说页组件被卸载，`onUnmounted` 销毁播放器 → 音乐必停。**修复方案**：播放器与页面解耦——

- **`client/src/musicStore.js`（新增）**：模块级单例播放器。原生 `Audio` 元素常驻内存，不随任何组件卸载；Vue 响应式状态（队列/进度/歌词/模式/音量）+ 操作方法（playList/playSong/playAt/jump/seek…）供任意组件订阅
- **`MiniPlayer.vue`（新增）**：底部常驻迷你播放条，挂在 App 根部渲染。可拖拽进度条、音量、播放模式（顺序→列表循环→单曲循环→随机）、播放列表面板（可移除单曲）、歌词面板（自动滚动跟随当前行）、Media Session（系统媒体键/锁台显示）、标签页标题显示「🎵 歌名 - 歌手」
- MusicView 移除 APlayer，只负责「选歌」；推荐歌单条目无需 songId，播放时按「歌名+歌手」在线搜索解析（resolveSong，精确匹配优先）
- **顺序播放**：队列自然播完自动切下一首（实测连播 4+ 首），播到队尾即停；解析/加载失败自动跳下一首（连续 4 次失败停止防死循环）

### 推荐歌单（6 张，治愈系）

看书伴读·轻音乐（夜的钢琴曲五/River Flows in You/天空之城…）、发呆放空·纯音乐、晚安·深夜治愈、雨天·咖啡馆、经典华语金曲、影视动漫经典。首页/音乐页/小说页同步更新治愈文案。

### 日间/夜间双主题

- `style.css`：夜间为 `:root` 默认变量，日间为 `html[data-theme='light']` 覆盖（全套 bg/surface/border/text/主色/遮罩/滚动条变量，金色主色日间加深保证对比度）
- 顶栏 ☀️/🌙 一键切换，localStorage 记忆；`index.html` 内联脚本在挂载前设主题（防刷新闪色）；默认跟随系统 `prefers-color-scheme`
- 清理全部硬编码颜色 → CSS 变量（ResultCard 封面兜底/收藏按钮、SearchBar、SourcesView 开关与弹窗、PlayerModal 遮罩、App logo/footer 等；封面上的深色遮罩保留——两主题下都盖在图上）

### 细节对齐（用户反馈）

- 音乐/小说页搜索框：输入框改固定高 38px 与按钮等高垂直居中
- 歌单卡：文字区与按钮间距、按钮 flex-shrink 防挤压、标题/描述行高统一
- 播放条：控制按钮 line-height:1 修 emoji 基线、模式胶囊内 emoji 与文字对齐、音量滑杆定高垂直居中
- 顶栏导航按钮行高统一

### 验证

- GUI 实测（1280×720）：歌单播放 → 切小说页/首页来回切换音乐连续（0:18→0:23→…不断）→ 一首播完自动切下一首（夜的钢琴曲五→River Flows in You→天空之城→Canon in D）→ 队列面板当前曲高亮 → 歌词面板当前行金色高亮 → 日间/夜间切换全页配色正确（双主题截图确认）

## 2026-09-08 · v0.2.6 音乐播放器换用 APlayer 插件

**背景**：用户要求音乐/小说等模块优先使用现成插件而非手写。调研后音乐侧采用 **APlayer 1.10.1**（知名开源 HTML5 播放器插件：歌词滚动/封面/主题色/控制条全内置），替换手写的播放条与歌词面板。

### 变更

- 安装 `aplayer` 依赖；MusicView 播放区改为 APlayer 实例（`lrcType 2` 直传 LRC 文本，插件内置解析与当前行高亮），深色主题 CSS 适配（金色主题色、歌词区透明渐隐）

## 2026-09-08 · v0.2.5 📖 小说阅读频道

**背景**：按「聚合搜索 + 真实验证」模式新增看小说功能。与视频/音乐不同，文字小说站没有统一 JSON 接口，采用**规则代理解析**方案：借用开源项目 so-novel 的书源规则体系（每站一套 CSS 选择器：搜索/目录/正文 + 广告过滤正则），后端代理抓取并解析。

### 新增

- **后端**（`server/src/novel.js` + `src/novel-rules.json` + 路由 `/api/novel/search | toc | chapter`）
  - 通用规则引擎：搜索（GET/POST、UTF-8/GBK 表单编码自适应）、目录解析（含目录在章节页内的 fallback）、正文清洗（去广告标签/广告文案正则、段落还原）
  - SSRF 防护：URL 的 host 必须命中收录源白名单，否则 400
  - 依赖新增：cheerio（CSS 选择器）、iconv-lite（GBK 表单编码）
- **前端**（导航第三项「📖 小说」，#/novel，三态视图）
  - 搜索列表：书名/作者/最新章/来源徽章（95 本命中《斗破苍穹》）
  - 目录视图：N 章 + 多源切换 chip（某源失败自动换下一源）
  - 阅读器：段首缩进排版、字号 A-/A+（记忆）、上一章/下一章、进度自动记忆（下次搜索同书显示「读到 第X章」一键续读）

### 修复

1. **novel 路由被插入到 music/pic 回调内部**导致路由不生效（Cannot GET）：修正插入位置
2. 多个后端僵尸进程占用 3000 端口造成「新代码不生效」假象：启动前统一清理

### 已知限制

- 4 个可用源里以鸟书网为主力（书库全、结构稳）；悠久目录需 fallback、阅读库部分书缺失、顶点目录/正文暂不稳（保留规则待修）

- **文字小说**：无稳定公开标准 API（阅读类书源为爬虫规则引擎，维护成本高），暂不做
